
# React Leaflet OpenStreetMap Project

A React (Next Js Framework) application using **Leaflet** and **OpenStreetMap (OSM)** to display user location and reverse geocode addresses. Includes local geospatial storage and customizable map styles.


## Installation



```bash
git clone https://github.com/binnoodx/OpenStreetMaps.git
cd 
npm install
npm run dev
